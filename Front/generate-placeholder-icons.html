Предварительный просмотр

📝 Инструкция по установке:

  1. Нажмите "Скачать все иконки" или скачайте каждую по отдельности
  2. Распакуйте ZIP архив (если скачали все)
  3. Скопируйте все файлы в папку Front/public/
  4. Запустите npm run build
  5. Ваше PWA готово к установке!
